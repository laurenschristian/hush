# Changelog

All notable changes to Hush are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [0.4.0] - 2026-09-23

### Added
- App icon built with Icon Composer (Liquid Glass)
- Documentation: how it works, troubleshooting, contributing, security

## [0.3.0] - 2026-09-23

### Added
- `⌃⌥M` global hotkey to mute every mic, with a red menu bar icon while muted
- Remember volume per output device
- Pause Spotify when headphones disconnect
- Pause Spotify during calls and resume after
- Universal binary for Apple Silicon and Intel
- Release workflow and Homebrew cask

## [0.2.0] - 2026-09-22

### Added
- Never use a Bluetooth mic
- Switch output to headphones on connect and back on disconnect
- Last used player detection
- Spotify now playing in the menu bar

### Changed
- Renamed from PlayKey to Hush

## [0.1.0] - 2026-09-22

### Added
- Block Apple Music and open Spotify or SoundCloud instead
